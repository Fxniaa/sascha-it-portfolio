# 📚 Learning Insights: What I'm Discovering as an IT Student

Documenting the things I learn (and the things that confuse me) along the way.

## 💡 What I've Learned So Far
- Hardware and code work together. A sensor is useless until the code reads it properly.
- Planning the components and the logic first makes the build much less messy.
- Git and GitHub help me keep a clear record of my progress, step by step.

## 🐛 Challenges I Expect (and Want to Solve)
- **Sensor accuracy:** ultrasonic readings can jump around, so I'll need to test filtering or averaging.
- **Wiring errors:** one wrong pin can break everything, so I'll double-check each connection.
- **Turning distance into alerts:** deciding the right distance ranges for the buzzer.
