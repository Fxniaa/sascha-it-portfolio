# 🚗 Arduino Vehicle Parking Alarm

A distance-based parking alert system I'm building as part of my IT learning journey.

## 🎯 Goal
Learn how ultrasonic sensors measure distance and how to turn that data into a useful real-world alert.

## 🔧 Components
- Arduino Uno (ATmega328P)
- HC-SR04 ultrasonic sensor
- Buzzer
- Jumper wires and breadboard

## ⚙️ How It Works
1. The HC-SR04 sends an ultrasonic pulse.
2. The pulse bounces off an object (like a wall or a car).
3. Arduino measures the echo time and calculates the distance.
4. The closer the object, the faster the buzzer beeps.
